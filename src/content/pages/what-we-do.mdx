  We find the valuable data already sitting inside a service business — usually
  dormant, usually scattered across a scheduling tool, an inbox, a spreadsheet
  and somebody's memory — build the operating system that captures it as a
  by-product of work already being done, turn it into the small number of views
  that answer the questions an owner actually asks, and point it at the
  activities that generate revenue. Four moves, in order, because each one is
  worth nothing without the one before it.
